# Manual QA Team

A standalone agentic manual-QA team for web and mobile apps — it authors and
sizes cases when needed, runs them live (web via Playwright MCP, mobile via
Appium), and reports.

## Install

```bash
npx github:arozumenko/sdlc-skills init --factory manual-qa
```

See [`README.md`](README.md) for the roster and how the team works.
