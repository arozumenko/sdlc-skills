# T-7 — Export invoices as CSV

**Story.** As an accountant I want to export the invoices as CSV so I can load them into the spreadsheet our auditors use.

## Acceptance criteria

1. `node src/cli.js export --csv` prints CSV to stdout and exits 0.
2. The first line is the header `id,customer,amount,issued`.
3. There is one row per invoice in `data/invoices.json`, in file order.
4. Values containing a comma are quoted (RFC 4180), e.g. `"Fabrikam, Ltd"`.

## Notes

- No new dependencies.
- Out of scope: other formats, filtering.
