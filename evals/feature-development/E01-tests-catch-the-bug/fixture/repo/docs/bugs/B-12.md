# B-12 — Members using SAVE10 are under-charged

**Severity:** major (revenue)
**Reported by:** finance reconciliation, 2026-10-02

A member checking out a 10000-cent basket with coupon `SAVE10` was charged **8075** cents. Per `docs/pricing.md` the total should be 10000 − 1000 (coupon) = 9000, then 5% member discount = **8550**.

Orders with only a coupon, or only membership, reconcile correctly.

Steps: `priceOrder({ items: [{ unitPrice: 10000, qty: 1 }], coupon: "SAVE10", member: true })` → 8075, expected 8550.
