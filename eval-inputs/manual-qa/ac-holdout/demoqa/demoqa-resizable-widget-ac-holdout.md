# Acceptance criteria — demoqa-resizable-widget-ac-holdout

## Feature: Resizing a Box via Corner Drag

As a user, I want to drag the bottom-right corner handle of a resizable box,
so that I can make the box bigger.

Acceptance Criteria:
- Dragging the bottom-right resize handle down and to the right increases
  the box's width and/or height compared to its starting size.
