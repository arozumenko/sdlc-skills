# Acceptance criteria — demoqa-droppable-widget-ac-holdout

## Feature: Drag-and-Drop Onto a Drop Target (Droppable)

As a user, I want to drag an item onto a designated drop area, so that the
page visibly confirms it was received.

Acceptance Criteria:
- On the Simple tab, dragging the draggable box onto the drop target changes
  the drop target's appearance/text to show the drop was registered.
- On the Accept tab, dragging the draggable box onto that tab's drop target
  changes the drop target's appearance/text to show the drop was registered,
  the same way it does on the Simple tab.
