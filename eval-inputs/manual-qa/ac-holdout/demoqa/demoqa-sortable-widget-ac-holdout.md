# Acceptance criteria — demoqa-sortable-widget-ac-holdout

## Feature: Drag-to-Reorder List (Sortable)

As a user, I want to reorder items in a list by dragging them, so that I can
arrange them in whatever order I prefer.

Acceptance Criteria:
- Dragging the first item in the list to the last position moves it there;
  the remaining items shift up by one position each and keep their relative
  order.
