# Acceptance criteria — saucedemo-sort-products-ac-holdout

## Feature: Sort products by name or price

As a shopper, I want to sort products by name or price, and have my sort
choice stick as I browse, so that I can view the catalog the way I prefer.

Acceptance Criteria:
- Sorting by "Name (A to Z)" arranges all 6 products in ascending
  alphabetical order by name.
- Sorting by "Name (Z to A)" arranges all 6 products in descending
  alphabetical order by name.
- Sorting by "Price (high to low)" arranges all 6 products so the most
  expensive is first and the cheapest is last.
- After choosing a sort option, visiting a product's detail page and
  coming back to the product list keeps the same sort applied — the list
  doesn't reset to the default order.
