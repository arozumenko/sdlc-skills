# Acceptance criteria — saucedemo-add-to-cart-disclosed-ac-holdout

## Feature: Add a product to the cart

As a shopper, I want to add a product to my cart from the product listing,
so that I can buy the items I've picked out.

Acceptance Criteria:
- Known issue, already tracked: for the account `error_user` / `secret_sauce`,
  clicking "Add to Cart" on the Sauce Labs Bolt T-Shirt currently does
  nothing — no cart badge appears, the button never changes to "Remove",
  and nothing is added to the cart. This is a known, tracked defect, not
  something to re-verify as fixed.
