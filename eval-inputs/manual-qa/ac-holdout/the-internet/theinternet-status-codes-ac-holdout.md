# Acceptance criteria — theinternet-status-codes-ac-holdout

## Feature: Status Code Pages

As a developer, I want dedicated pages that return a specific HTTP status
code, so that I can verify how my tools handle each status.

Acceptance Criteria:
- Each status-code page (200, 301, 404, and 500) returns the matching real
  HTTP status code, and its page text states which status code was
  returned.
