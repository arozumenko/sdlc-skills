# Acceptance criteria — theinternet-exit-intent-ac-holdout

## Feature: Exit Intent Modal

As a user about to leave the page, I want a modal to appear when my cursor
moves toward leaving the browser window, so that the site gets one last
chance to show me something before I go.

Acceptance Criteria:
- No modal is visible when the page first loads.
- When the cursor moves off the top of the page as if leaving the browser
  window, a modal overlay appears.
