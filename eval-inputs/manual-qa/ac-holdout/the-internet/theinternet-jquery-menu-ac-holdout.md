# Acceptance criteria — theinternet-jquery-menu-ac-holdout

## Feature: JQuery UI Menu

As a user, I want a menu with enabled and disabled items to behave
correctly, so that I only interact with items that are actually meant to be
usable.

Acceptance Criteria:
- The menu's "Disabled" item is visibly shown as disabled and does not
  respond to interaction.
- Hovering the menu's "Enabled" item shows an active/focused state and
  reveals a nested submenu of further options.
