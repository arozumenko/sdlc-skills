# Acceptance criteria — theinternet-drag-and-drop-ac-holdout

## Feature: Drag and Drop

As a user, I want to drag one box onto another and have them swap places,
so that I can reorder items by dragging.

Acceptance Criteria:
- Dragging box A onto box B swaps their labels — box A's position now shows
  "B" and box B's position now shows "A".
