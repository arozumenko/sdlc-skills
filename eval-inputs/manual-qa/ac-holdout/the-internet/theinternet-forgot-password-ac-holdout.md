# Acceptance criteria — theinternet-forgot-password-ac-holdout

## Feature: Forgot Password

As a user who can't remember my password, I want to submit my email address
on a "Forgot Password" form, so that I can start the process of resetting
it.

Acceptance Criteria:
- Entering a valid-looking email address and submitting the Forgot Password
  form shows a confirmation that a password-reset email was sent to that
  address, with no error on the page.
