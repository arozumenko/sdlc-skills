# Acceptance criteria — theinternet-file-upload-ac-holdout

## Feature: File Upload

As a user, I want to upload a file from my computer, so that I can confirm
it was received and share it with others via the download list.

Acceptance Criteria:
- Choosing a local file and submitting the upload form shows a success
  message confirming the upload, with the uploaded file's name echoed back
  exactly.
- After uploading, the file's name appears in the public downloadable-files
  list.
