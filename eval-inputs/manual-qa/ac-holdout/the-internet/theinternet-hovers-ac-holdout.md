# Acceptance criteria — theinternet-hovers-ac-holdout

## Feature: Hover Profile Captions

As a user, I want to hover over a picture and see who it belongs to, so
that I can find and open that person's profile.

Acceptance Criteria:
- Hovering over any of the three pictures on the page reveals a caption
  with a name and a "View profile" link.
- Each of the three pictures' profile links points to a distinct person's
  profile — no two point to the same one.
