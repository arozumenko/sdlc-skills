## Feature: Cookie-Controlled Login Simulation

As a user, I want to simulate logging in and out and have the page clearly reflect my current state, so that I can test login-dependent behavior without a real account system.

Acceptance Criteria:
- Triggering the simulated login changes the page's displayed state to logged in, and this persists across a page reload.
- Triggering the simulated logout reverts the page's displayed state back to logged out.
