## Feature: File Upload

As a user, I want to upload a file either by choosing it from a file picker or by dragging it onto the page, so that I can use whichever method is more convenient.

Acceptance Criteria:
- Selecting a file via the file chooser control shows a success status once the upload completes.
- Dragging a file directly onto the page's drop zone also shows a success status once the upload completes.
