## Feature: Frameset Page Content

As a QA engineer, I want to verify that each area of a classic frameset layout shows its own distinct content, so that I know the layout is correctly assembled from independent documents.

Acceptance Criteria:
- The page is built from five named frame areas (top, left, middle, right, and footer).
- Each frame area's content can be read independently, and the content differs between the areas, confirming each is a genuinely separate document.
