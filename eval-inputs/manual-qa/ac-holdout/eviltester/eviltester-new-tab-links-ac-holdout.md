## Feature: Links That Open a New Tab

As a user, I want certain links to open in a new tab while keeping my current page open, so that I don't lose my place.

Acceptance Criteria:
- Clicking a plain link marked to open in a new tab opens the destination in a new tab, and the original tab remains on the current page.
- Clicking a second, script-driven link that programmatically opens a new tab behaves the same way — a new tab opens with the correct destination, and the original tab is unaffected.
