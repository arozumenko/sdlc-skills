## Feature: Simulated Alert Dialog

As a user, I want the page's alert-style dialog to work correctly even though it isn't a real browser dialog, so that I still get clear feedback when I trigger it.

Acceptance Criteria:
- Clicking the button that triggers the dialog shows an on-page dialog with an accept/dismiss control.
- Responding to the dialog closes it and returns the page to a normal interactive state, with the outcome reflected on the page.
