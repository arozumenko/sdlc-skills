## Feature: 7-Character Validator

As a user, I want the app to tell me whether my input is a valid 7-character value, so that I can correct it if it isn't.

Acceptance Criteria:
- Entering a valid 7-character alphanumeric value (letters, digits, or `*`) and checking it shows a "Valid Value" result.
- Entering a value of the wrong length and checking it shows a distinct invalid-value result.
